# Jack Petrie - Film Student Portfolio

A modern, animated portfolio website showcasing the work of film student Jack Petrie. Built with React, Next.js, and Framer Motion for stunning animations and effects.

## 🎬 Features

- **Clean Design**: Minimalist aesthetic with maroon accent colors
- **Smooth Animations**: Powered by Framer Motion for engaging user experience
- **Responsive Layout**: Optimized for all devices and screen sizes
- **Film Showcase**: Dedicated sections for film projects and reels
- **Interactive Elements**: Hover effects and scroll-triggered animations
- **Modern Tech Stack**: Built with Next.js, TypeScript, and Tailwind CSS

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ and npm

### Installation

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```

3. Open [http://localhost:3000](http://localhost:3000) in your browser

### Building for Production

```bash
npm run build
npm start
```
